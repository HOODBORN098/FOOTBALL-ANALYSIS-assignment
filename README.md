# International Football Results Analysis (1872–2026)

This project contains a comprehensive data analysis of international football match results using the Kaggle dataset. It explores historical trends, goal distributions, and team performance.

## Project Structure
- `Football_Analysis.ipynb`: The main Jupyter Notebook containing the full analysis, logic, and visualizations.
- `results.csv`: The dataset containing historical match data.

## Key Insights
- **Total Matches:** 49,287+
- **Home Advantage:** Statistically significant with a ~49% home win rate.
- **Top Team:** Brazil holds the record for the most historical wins.
- **Average Scoring:** ~2.94 goals per match.

## Requirements
- Python 3.x
- Pandas
- Matplotlib
- Seaborn

## How to Run
1. Clone the repository.
2. Ensure dependencies are installed: `pip install pandas matplotlib seaborn`.
3. Open `Football_Analysis.ipynb` in Jupyter Notebook or VS Code.
