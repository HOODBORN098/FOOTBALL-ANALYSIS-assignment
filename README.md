# International Football Results Analysis (1872–2026)

This project contains a comprehensive data analysis of international football match results using the Kaggle dataset.

## Assignment Sections
- [Basic Exploration](Basic_Exploration.md)
- [Goals Analysis](Goals_Analysis.md)
- [Match Results](Match_Results.md)
- [Visualization](Visualization.md)

## Project Files
- `Football_Analysis.ipynb`: The main Jupyter Notebook with all code and visualizations.
- `results.csv`: The raw dataset.

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install pandas matplotlib seaborn`.
3. Open the notebook or read the markdown files for the analysis.
